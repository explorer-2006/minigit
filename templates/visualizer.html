🔗 Commit Linked List (next pointer traversal)

Singly Linked List
MiniGit stores the entire repository history in memory as a singly linked list of CommitNode structures. Nodes are ordered chronologically from oldest (head of list) to latest. Arrows represent the next pointer in memory.

🌳 Commit History Tree (Parent-Child Hierarchy)

N-ary Directed Tree
Every commit points back to its parentId. Branching occurs when multiple child commits share the same parent node. Active branch references and HEAD pointers are highlighted above their corresponding target commits.

🥞 Undo Stack (LIFO - Last In, First Out)

Stack Data Structure
Whenever you make a commit or switch/revert, MiniGit pushes the previous branch state and HEAD pointer onto the undo stack. Running ./minigit undo pops the top element to restore the prior state.
